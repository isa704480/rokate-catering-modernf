# Как редактировать сайт

Короткая инструкция для Rokate Catering.

## Как войти

1. Откройте `https://<адрес сайта>/admin`
2. Нажмите **Login with GitHub** и войдите в свой аккаунт GitHub.

Всё, что вы меняете, сохраняется в вашем репозитории. Через 1–2 минуты после
сохранения сайт обновляется сам. Обновите страницу сайта, чтобы увидеть результат.

## Главное правило: два языка

У каждого текста два поля — **(RU)** и **(EN)**. Заполняйте оба.
Если английский оставить пустым, на английской версии сайта покажется русский текст.

## Что где лежит

| Раздел в панели | Что меняет |
|---|---|
| **Настройки сайта** | Телефон, WhatsApp, Telegram, Instagram, email, часы работы |
| **Главная страница** | Все блоки главной: первый экран, «О Rokate», шаги работы, доп. услуги |
| **Направления кейтеринга** | Пять блоков: яхты, открытия, корпоративы, частные ужины, свадьбы |
| **Кейтеринг-пакеты** | Названия, состав, цены «от», фото |
| **Портфолио** | Фотографии мероприятий с подписями |
| **Отзывы** | Пока пусто. Добавляйте только настоящие отзывы |
| **Страницы** | Меню, Яхт-кейтеринг, Корпоративный, Партнёрам, Политика, Вопросы |
| **SEO** | Заголовки и описания для Google |

## Частые задачи

### Поменять цену пакета

**Кейтеринг-пакеты** → выберите пакет → поля **Цена (RU)** и **Цена (EN)** →
**Publish** вверху справа.

Пишите цену так, как она должна выглядеть на сайте: `от AED 85 / гость`.

### Добавить новый пакет

**Кейтеринг-пакеты** → **New Пакет** → заполните поля → **Publish**.
Поле **Порядок** — чем меньше число, тем левее пакет в ленте.

### Добавить работу в портфолио

**Портфолио** → **New Работа** → загрузите фото, заполните название, тип
мероприятия и место → **Publish**.

Лучше всего смотрятся вертикальные фотографии. Горизонтальные тоже подойдут —
сайт обрежет их по центру.

### Заменить фотографию

Откройте нужную запись → нажмите на фото → **Choose an image** →
**Upload** (загрузить новое) или выберите из уже загруженных → **Publish**.

### Скрыть что-то, не удаляя

В пакетах, портфолио, отзывах и направлениях есть переключатель
**Скрыть на сайте**. Включите его — запись останется в панели, но с сайта исчезнет.

### Поменять текст на главной

**Главная страница** → **Блоки главной**. Разделы идут в том же порядке,
что и на сайте, сверху вниз.

## Если что-то пошло не так

Любое изменение можно отменить: все версии сохраняются.
